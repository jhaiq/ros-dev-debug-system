## 使用注意

1. **Phase B 功能需要 backend 运行在有 ROS 2 环境的机器上**（机器人或装了 ros2 的仿真机），且 `ros2` 在 PATH 中；容器部署已满足。
2. **远程终端 / Python 控制台无认证**，按 Q2 结论仅限内网/可信环境使用。
3. rqt_action / JTC 需要 rosbridge 支持 action 协议（Q5 确认支持）。
4. 工作台透视保存在浏览器 localStorage，换浏览器/清缓存会丢失，可用导入/导出迁移。
